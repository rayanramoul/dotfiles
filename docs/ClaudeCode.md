# Claude Code

## Initial Setup

### Install Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

### Hooks

#### claude-diff

Adds a diff view hook so Claude Code shows a visual diff of file changes before applying them.

Source: https://github.com/gandarfh/claude-diff

```bash
# Clone and install
git clone https://github.com/gandarfh/claude-diff.git
cd claude-diff
./install.sh

# To uninstall hooks later
./install.sh --uninstall
```
